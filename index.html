# Channel Status Code Detail

Online means the stream sent valid data. Reachable means the server answered but blocks browsers from reading the result, so the stream is unverified. Adding a proxy in Scan settings removes that limit. Everything runs in your browser; playlists are never uploaded anywhere except to the stream hosts you are checking.
